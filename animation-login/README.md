# Animation Login

A simple animated Login and Signup application built using React.js, Node.js and Express.js.

## Features

- Login and Signup
- Show / Hide Password
- Remember Me
- Forgot Password
- Logout
- Login validation
- REST API connection
- CSS animations
- Responsive design

## Technologies Used

- React.js
- JavaScript
- CSS
- Node.js
- Express.js
- REST API
- Git & GitHub
